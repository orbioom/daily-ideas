# Volley — Party Questions Game

**Bundle:** com.orbioom.volley  
**Platform:** iOS 17+  
**Accent Color:** Vivid Orange #F97316  

## Overview

Volley is a bold, energetic party game app featuring Would You Rather, Truth or Dare, Never Have I Ever, and Icebreakers. 150+ built-in questions, custom question creation, category filtering, and no subscription. One-time Pro unlock at $1.99.

## Feature Screens

1. **HomeView** — 4 large gradient mode cards in a 2×2 grid; tap to set up a game
2. **GameSetupSheet** — Half-sheet with category picker and question count selector
3. **GameView** — Full-screen gradient question cards with animated swipe transitions, skip/next buttons, progress bar, and game completion overlay
4. **BrowseView** — Searchable question list with mode filter chips, grouped by mode, enable/disable toggles per question
5. **CustomQuestionsView** — Create, edit, and delete custom questions; enforces 5-question free limit
6. **SettingsView** — Haptics toggle, safe mode toggle, Pro upgrade, stats, data reset
7. **OnboardingView** — 3-page onboarding with animated gradient backgrounds

## Architecture

- **SwiftData** persistence: `Question`, `GameSession`, `AppSettings`
- **@Observable** engine: `VolleyEngine` — shuffles, tracks index, answered/skipped counts
- Static question database: `Engine/QuestionLibrary.swift` — 150 questions across 4 modes
- Seeds questions on first launch via `modelContext.insert()`
- Mode-specific gradients defined in `VolleyTheme`
