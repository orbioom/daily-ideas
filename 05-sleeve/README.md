# Sleeve

A trading card collection tracker for Pokemon, Magic: The Gathering, and sports cards.

## Features

- Manually catalog cards with full metadata (set, number, rarity, condition, value)
- Build and manage decks across multiple games and formats
- Maintain a want list with priority levels and max price targets
- Track approximate collection value and statistics
- Deep purple / silver visual theme

## Tech Stack

- SwiftUI 5 + SwiftData
- iOS 17+ deployment target
- XcodeGen (`project.yml`)

## Getting Started

```bash
brew install xcodegen
cd ios
xcodegen generate
open Sleeve.xcodeproj
```

## Games Supported

- Pokemon
- Magic: The Gathering
- Yu-Gi-Oh!
- Sports Cards
- Other
