# Keys — Piano Learning App

**Bundle:** com.orbioom.keys  
**Platform:** iOS 17+  
**Accent Color:** Forest Green #2D7A4F  

## Overview

Keys is a native iOS piano learning app that teaches you to play piano through interactive exercises, real audio synthesis, and structured lessons. No subscription — one-time Pro unlock at $4.99.

## Feature Screens

1. **HomeView** — Daily practice prompt, streak ring, goal progress, recent sessions, quick-start module cards
2. **CurriculumView** — 5-module browser with per-module progress bars and lesson counts
3. **LessonListView** — Lesson list per module with type badges and completion checkmarks
4. **PianoSessionView** — Interactive exercise view: instruction cards, piano keyboard, ADSR audio, correct/wrong feedback, session completion summary
5. **FreePianoView** — Free-play mode with full scrollable keyboard (MIDI 36–96), real-time note name display
6. **ProgressView** — Streak counter, 14-day practice bar chart (Swift Charts), module completion rings, session history
7. **SettingsView** — Sound/haptics/label toggles, daily goal picker, Pro upgrade, reset progress
8. **OnboardingView** — 3-page animated onboarding

## Architecture

- **SwiftData** persistence: `PracticeSession`, `UserSettings`
- **@Observable** view models: `PianoEngine`
- **AVAudioEngine** for piano synthesis: ADSR envelope, additive harmonics (fundamental + 2nd + 3rd + 4th partials)
- **Swift Charts** for practice history visualization
- Static curriculum data in `Engine/Curriculum.swift` (5 modules, 32 lessons)

## Curriculum

| Module | Lessons |
|--------|---------|
| Getting Started | 6 (meet keys, scales, hand position) |
| Note Mastery | 8 (identify each note A–G + random drill) |
| Simple Melodies | 6 (Twinkle, Mary, Hot Cross Buns, Ode to Joy, Jingle Bells, Happy Birthday) |
| Basic Chords | 6 (C, G, F major; Am, Dm, Em) |
| Ear Training | 6 (identify pitches by ear) |
