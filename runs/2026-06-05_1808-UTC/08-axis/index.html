Method & References

What PCA does: Principal Component Analysis finds the directions (principal components) in feature space along which the data varies the most. Projecting data onto these directions gives a low-dimensional summary that preserves as much variance as possible. The first PC captures the most variance; each subsequent PC is orthogonal (uncorrelated) to all previous ones.

How to read the plots:

  • Scores scatter: each point is one sample. Tight clusters = similar samples. Separation along PC1 = the dominant pattern explains that split.
  • Scree plot: bar height = fraction of total variance each PC explains. The elbow point suggests how many PCs to retain. The red line is cumulative variance.
  • Loadings biplot: arrows show how original features map onto the PCs. Long arrow = feature contributes heavily to that PC. Arrows pointing the same direction = positively correlated features.

Computation steps (this tool):

  • 1. Mean-centering: subtract each feature's mean so the origin is the centroid.
  • 2. Autoscaling (optional): divide each feature by its sample standard deviation (z-score). Recommended when features have different units or very different scales. Makes the covariance matrix equivalent to the correlation matrix.
  • 3. Covariance matrix: compute the p×p symmetric covariance matrix C = (1/(n−1)) ZᵀZ, where Z is the centered/scaled n×p data matrix.
  • 4. Jacobi eigendecomposition: iteratively apply Givens rotations to diagonalize C (cyclic Jacobi algorithm; converges in a few sweeps for small p). Eigenvalues (diagonal of the diagonalized matrix) = variances along each PC; eigenvectors (accumulated rotation product) = PC directions (loadings).
  • 5. Sort & project: sort eigenpairs by eigenvalue descending; multiply Z by the top eigenvectors to get scores.

Honest simplifications: The Jacobi solver works excellently for small p (≤ ~30). For very large p, SVD-based approaches are more efficient. This tool uses sample covariance (ddof=1). Sign of eigenvectors is arbitrary (flipping a PC axis does not change the geometry). The tool does not perform cross-validation or significance testing.

Sanity checks: After decomposition, the tool verifies (a) eigenvectors are orthonormal (|dot| < 1e-8, |norm−1| < 1e-8) and (b) explained variance ratios sum to 1 (±1e-6). Results displayed in the stats strip.
