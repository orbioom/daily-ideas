# Pip

**A clean, fair, ad-free Yahtzee-style dice game for iOS.**

Five dice, three rolls, thirteen ways to score. Pip is the dice game *Yahtzee With Buddies*
should have been: no ads, no energy timers, no pop-ups begging for coins. Just a beautiful
green-felt table, solo and pass-and-play, real CPU opponents, a shared Daily challenge, and
honest statistics — backed by a one-time Pro unlock instead of an endless IAP funnel.

**Problem & audience.** Dice games are an evergreen, top-grossing mobile genre, but the
incumbents are bloated with ads and aggressive monetization. Pip is for everyone who loves
the classic five-dice game and wants a calm, premium, ad-free way to play alone, with friends
around one phone, or against a thinking CPU.

## Features

- **Core game engine** — 5 dice, up to 3 rolls per turn, hold/unhold any dice between rolls,
  all 13 categories with correct scoring, upper bonus (+35 at 63), Yahtzee bonus (+100 each
  extra) and full **Joker** category-placement rules.
- **Modes**
  - **Solo** — beat your own best.
  - **Pass & Play** — 2 players free, up to 4 with Pro, with turn rotation and per-player columns.
  - **vs CPU** — 1–3 computer opponents across three difficulties (Casual / Sharp / Master),
    each driven by a deterministic expected-value heuristic.
  - **Daily** — a date-seeded dice sequence that is identical for everyone that day; one high
    score, with a Pro archive of past runs.
- **Game table** — green-felt dice tray with a tasteful tumble animation, tap-to-hold, a
  rolls-left indicator, a live scorecard with score previews on every open category, per-player
  totals, a turn indicator, and an end-of-game winner overlay with final standings.
- **Auto-hold suggestions** — optional dashed hints showing which dice to keep.
- **Stats** (Swift Charts) — games played, best/average score, total Yahtzees, win-rate vs CPU,
  a recent-score trend line, score distribution histogram, and average-by-category bars.
- **History** — every finished game with date, mode, players, scores and winner, filterable by
  mode, with a per-game detail scorecard. Swipe to delete.
- **How to Play** — full rules and a per-category scoring reference, including bonuses and Jokers.
- **Onboarding** — a four-page intro that explains the game and sets the onboarding flag.
- **Settings** — Appearance (System/Light/Dark), Haptics, Dice-roll animation speed (incl. Off),
  Auto-hold suggestions, Sort-scorecard-by-best-score, plus Unlock/Restore Pro, reset data, and About.
- **Polish** — empty states everywhere, success toasts, haptics gated by settings, full Dynamic
  Type, accessibility labels on dice ("die showing 5, held"), scorecard rows and charts, and a
  Reduce-Motion path that resolves rolls instantly.
- **Persistence** — SwiftData for games, profiles and Daily results; `@AppStorage` for prefs.
  ~30 realistic past games (generated by actually playing them out) plus profiles are seeded once
  on first launch.

## Run

1. `brew install xcodegen` (one-time).
2. In `ios/`, run `xcodegen generate` (or `./gen.sh` at the repo root).
3. Open `Pip.xcodeproj` in Xcode 15+, pick an iOS 17+ simulator, and press **Cmd+R**.

### Free signing

No paid account needed. In Xcode select the **Pip** target → **Signing & Capabilities**,
choose your personal Apple ID team, and let Xcode manage signing automatically. The bundle id is
`com.orbioom.pip` — change it if it collides with an existing profile.

## Tech notes

- **iOS 17+**, **SwiftUI**, **SwiftData** (`@Model`/`@Query`/`modelContainer`), **Swift Charts**,
  Observation (`@Observable`) for the game view-model and the engine.
- **Architecture** — a pure, deterministic core (`Scorer`, `GameEngine`, `CPUStrategy`,
  `StatsEngine`) with an injected `SeededRNG` (SplitMix64). Determinism powers the Daily challenge,
  reproducible CPU play and seed data. Views are thin; all rules live in the engine.
- **Design language** — a modern "green felt" table: emerald accent (`#18A558`, matching the asset
  AccentColor), ivory/cream dice with crisp pips, rounded SF type, dynamic light/dark colors for
  AA contrast in both modes. Confident and calm, never gaudy casino.
- **Monetization** — one-time **Pip Pro** unlock (**$2.99**), simulated via `@AppStorage("isPro")`
  and StoreKit-ready; unlocks CPU opponents, extra table/dice themes, full stats and the Daily
  archive. The free core (Solo, 2-player Pass & Play, basic stats) is fully playable.
- **Why it can boom** — dice games are an evergreen top-grossing genre, but the incumbents are
  ad/IAP-bloated; Pip is the clean, fair, ad-free version with real pass-and-play and CPU play.

## Self-review

I re-read every Swift file and verified by hand:

- **Imports** present and minimal (`SwiftUI`, `SwiftData`, `Charts`, `Foundation`, `Observation`,
  `UIKit` only where used).
- **iOS 17 only** — `NavigationStack` (no `NavigationView`), two-parameter `.onChange(of:) { _, new in }`,
  no `@Previewable`, no iOS-18 SwiftData/SwiftUI symbols, no `@retroactive`. SwiftData `#Predicate`,
  `FetchDescriptor`, `@Query` and `modelContainer` type-check.
- **Safety** — no `try!`, `as!`, or force-unwraps on user paths; the only `fatalError` is the
  documented-unreachable in-memory `ModelContainer` fallback. All array access is index-guarded;
  JSON encode/decode is non-throwing with fallbacks; no unguarded division.
- **No banned strings** — no TODO/FIXME/placeholder/stub/"coming soon"/etc.
- **Schema** — all three `@Model` types (`GameRecord`, `PlayerProfile`, `DailyResult`) are listed
  in the `Schema([...])` in `PipApp.swift`.
- **Property-wrapper ownership** — `@StateObject AppSettings` (ObservableObject) at app root;
  `@Observable` `GameViewModel`/`GameEngine` held by `@State`; no mixing of `@Observable` with
  `@StateObject`.

**Scoring verified mechanically** (ported the pure `Scorer` + `GameEngine` Joker/bonus logic and ran
the exact hand cases):
- **Full House** — `{3,3,3,2,2}` → 25; `{4,4,4,4,4}` → 0 (five-of-a-kind is not a natural full house);
  `{5,5,5,5,2}` → 0; `{6,6,2,2,2}` → 25 (pair+triple in either order).
- **Small Straight** — `{1,2,3,4,6}`, `{1,1,2,3,4}`, `{2,2,3,4,5}`, `{3,4,5,6,6}` → 30; `{1,2,4,5,6}` → 0.
- **Large Straight** — `{1,2,3,4,5}` and `{2,3,4,5,6}` → 40; `{1,2,3,4,6}` → 0.
- **Yahtzee bonus / Joker** — first Yahtzee with the box open scores 50 and awards no bonus; an extra
  Yahtzee while the box is already 50 awards **+100**, and when the matching upper box is filled the
  Joker lets it be placed as Full House (25) / Small (30) / Large (40) straight; if the matching upper
  box is still open the Joker stays inactive (upper box must be used naturally). A Yahtzee box scored as
  0 awards no future bonus, matching standard rules.
- **Game flow** — simulated full games for 1, 2 and 4 players: every player fills all 13 categories,
  turn rotation and winner/tie determination are correct, and identical seeds reproduce identical
  totals (determinism confirmed).

**Attestation:** to the best of a careful by-hand review, the sources compile against the iOS 17 SDK,
contain no force-unwraps/`try!`/`as!` on user paths, no banned APIs or placeholder strings, register
every `@Model` in the schema, and implement the complete game with correct scoring (including straights,
full house, and the Yahtzee bonus/Joker rules) verified against the cases above.
