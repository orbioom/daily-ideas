# Decay Notes

Notes that literally fade over time — mirroring how real memory works.

## The Idea

Every note has a configurable lifespan: 1 day, 7 days, 30 days. As time passes, the note's opacity
decreases, its vitality bar drains, and a "fading" chip appears when it drops below 35%. When a note
reaches near-zero, it goes nearly invisible — a ghost of something you thought mattered.

You can **refresh** any note (reset its timestamp, re-asserting it matters) or let it vanish.
The interface never nags you. It just shows you what you've tended and what you've left to fade.

## Why It's Interesting

Most note apps treat all notes as equally permanent. But memory doesn't work that way — ideas decay
unless revisited. This app externalizes that truth into UI: the act of opening the app and seeing
what's fading *is* a spaced repetition prompt, without any quiz, score, or gamification.

The result is a note-taking tool that teaches you what you actually care about through neglect.

## How to Run

Open `index.html` in any browser. No install required. All data persists in `localStorage`.

**Keyboard:** `Ctrl+Enter` (or `Cmd+Enter`) to plant a note.

## Orbioom Feeling

Mist background, Liquid Glass panels with a fine vitality bar that uses the live green accent (#86C79A).
Notes fade like morning mist — opacity and text color both decrease. The glass and mist are constant;
only the notes themselves carry the dimension of time. Calm, purposeful, slightly melancholy.
