# Spar — Boxing & Striking Martial Arts Trainer

Your private on-device training companion for boxing, kickboxing, Muay Thai, MMA, and more. No subscription, no cloud.

## Features

- **Multi-discipline support** — Boxing, Kickboxing, Muay Thai, MMA, Karate, Taekwondo with discipline-specific icons
- **Session logging** — 8 session types (Shadow Boxing, Bag Work, Pad Work, Sparring, Mitts, Conditioning, Drills, Technical Drills) with duration, rounds, intensity (1-5), mood, focus areas, partner name
- **Fighter profile** — discipline, stance (Orthodox/Southpaw/Switch), weight class, rank/belt, training years, goals
- **Technique Library** — 35 seeded striking techniques across 8 categories (Punches/Kicks/Elbows/Knees/Defense/Footwork/Clinch/Combos) with descriptions, mastery levels (Learning→Mastered), practice counter with auto-mastery advancement, favorites
- **Fight Record** — log amateur and pro fights with opponent, event, result (W/L/D/NC), method (KO/Decision/etc), round, notes; full W-L-D record display with KO count and win %
- **Insights** — 8-week weekly training minutes chart, session type donut, intensity breakdown, technique mastery bars
- **Dashboard** — fighter hero card with streak, weekly progress bar vs goal, quick stats, last session card, fight record summary
- **55 seeded training sessions** + 35 techniques + 8 fight records from day one

## How to Run

1. `brew install xcodegen`
2. `cd ios && xcodegen generate`
3. Open `Spar.xcodeproj` in Xcode 15+
4. Run on simulator or device (free signing: set your Team)
