# Across — a daily mini crossword

**Across** is a clean, ad-free daily mini crossword for iPhone (native SwiftUI, iOS 17). A fresh hand-made puzzle every day, a generous archive of 5×5 Minis and 7×7 Midis, an on-screen keyboard built for the grid, and a one-time unlock — no subscription, no ads, ever. It's the NYT-Mini experience without the paywall-and-clutter tax.

Accent color: **crossword-red `#C8472F`**. Design language: a crisp newspaper "puzzle page" — warm newsprint paper in light mode, deep ink in dark mode, a tasteful serif masthead, and a precise grid.

## What's in the app

### Feature screens (TabView)
1. **Today** — the daily hero. A deterministic puzzle for the date, a big Play / Resume / Review CTA, current streak, best time, and total solved. When today's is solved, a "play a random puzzle" card appears to keep the streak going.
2. **Board (Solver)** — the interactive crossword:
   - Tap a square to select; tap again to flip Across ⇄ Down.
   - A **clue bar** with the current clue and prev/next arrows.
   - A custom **on-screen QWERTY keyboard** (the system keyboard never shifts the grid).
   - **Auto-advance** within a slot, **skip-filled** when changing clues, both toggleable.
   - A **Check / Reveal** menu for square / word / puzzle, with optional confirm-before-reveal.
   - Incorrect cells flagged after a Check; revealed cells tinted.
   - A **pause-safe timer** that stops on solve and when the app backgrounds.
   - A **win celebration** that respects Reduce Motion.
   - Progress is persisted continuously, so you resume exactly where you left off.
3. **Archive** — the full library as a card grid with solved status, time, and difficulty, plus All / To-do / Solved filters. Free users get the daily + a starter set; the rest is Pro.
4. **Stats** — Swift Charts: solve-time trend, solves-over-time (weekly), average time by difficulty, plus headline numbers for current streak, best streak, puzzles solved, average time, completion rate, and fastest solve. Computed asynchronously with a brief loading state.

Plus **Onboarding** (3 pages, first run) and a **Settings** screen.

### The crossword engine (correctness-first)
Each puzzle is authored as a **grid of solution letters** (`#` = black cell). The `CrosswordEngine` *derives* everything from the grid — slot boundaries, standard left-to-right / top-to-bottom **numbering**, and the answer for each slot. Nothing is hand-numbered, which eliminates a whole class of authoring bugs. The engine:
- validates grids are rectangular and contain only `A–Z`/`#` (malformed grids fall back to a calm error state, never a crash);
- guards **every** array access and never force-unwraps;
- provides selection/navigation, advance/back within a slot, next/previous slot, and check / reveal / completion for cell, word, and whole puzzle.

The **PuzzleBank** ships **33 puzzles** (30 5×5 Minis + 3 7×7 Midis), each tagged easy / medium / hard, with a clue for every derived slot. Every across **and** down run of length ≥ 2 is a real common English word — the grids were generated by a constraint solver against a curated word list and then verified, so the fills are clean.

### Persistence (SwiftData)
- `PuzzleProgress` — `puzzleID`, row-major `enteredLetters` / `revealedMask` / `checkedMask`, `completed`, `elapsedSeconds`, `solvedAt`, `lastPlayedAt`. Drives resume.
- `DailyResult` — `dateKey` (yyyy-MM-dd), `puzzleID`, `solved`, `elapsedSeconds`, `usedCheck`, `usedReveal`, difficulty. Drives streaks and stats.

Small flags (`isPro`, `hasOnboarded`, prefs) live in `@AppStorage`.

### Settings (real, persisted prefs)
Auto-advance · Skip-filled · Confirm-before-reveal · Show timer · Pencil mode · Haptics · Board theme (Classic / Ink / High-Contrast) · Load sample data · Reset progress · About · Pro / Restore. Each toggle changes real behavior.

## Monetization

- **Free**: the daily puzzle, plus a starter set of **6** archive puzzles, plus the Classic theme. No ads, ever.
- **Across Pro — one-time `$2.99`**: unlocks the **entire archive** (and all future puzzles) and the **Ink** & **High-Contrast** board themes.
- **Never a subscription, never ads.**

StoreKit is **not** wired in this build (it isn't signed). The paywall's "Unlock" sets `isPro = true` and "Restore Purchase" is present; both are honest placeholders for the real StoreKit 2 purchase/restore flow in production.

## Why it can boom

The NYT Mini / Crossword is hugely popular but lives behind a subscription, inside an app that's increasingly cluttered with other games, accounts, and upsells. A large audience just wants *the daily mini*, clean and quick. **Across** is exactly that: an ad-free, beautifully typeset daily mini crossword with a generous archive and a **single small one-time unlock** instead of a recurring bill. The crossword is a distinct, durable mechanic — different from Wordle / Spelling Bee / Connections — with daily-habit and streak loops already proven to retain. Undercutting the subscription with a one-time price, while being faster and calmer to use, is a sharp, defensible wedge.

## Architecture

```
ios/Across/Across/
  AcrossApp.swift            @main, ModelContainer (single try! = in-memory fallback)
  Theme/Theme.swift          palette + per-colorScheme dyn() + board ThemePalette
  Models/                    Puzzle, Difficulty, Clue; PuzzleProgress, DailyResult (@Model)
  Engine/                    CrosswordEngine, PuzzleBank, StatsEngine, StreakService
  ViewModels/                AppSettings, Pro, BoardViewModel
  Utilities/                 Haptics, DateKey, TimeFormat, SeedData
  Views/                     RootView, Onboarding, Today, Board (Grid/Clue/Keyboard/Win),
                             Archive, Stats, Settings, Paywall, Components
```

Built with SwiftUI, SwiftData, and Swift Charts for iOS 17. Everything stays on device — no account, no network.

## Self-review attestation

- **Build hygiene**: exactly one `@main` (`AcrossApp`); exactly one `try!` (the in-memory `ModelContainer` fallback in the `catch` block). No `as!`, no `fatalError`, no force-unwraps on user paths. Anti-stub grep (`TODO/FIXME/placeholder/…`) is clean.
- **Engine correctness**: the numbering algorithm was hand-verified against the standard crossword rules on multiple grids (e.g. the "Stagger" and "Midi" boards) and matches cell-for-cell. All grids are rectangular, uppercase `A–Z`/`#` only, and **every** across/down run of length ≥ 2 is a real word with **exactly one** clue (verified programmatically: 247 distinct answers, 0 missing, 0 extra). All engine indexing is bounds-guarded; malformed input yields a calm error state, not a crash.
- **DoD**: 4 substantive feature screens + Settings; first-run onboarding sets `hasOnboarded`; empty / loading / error / success states throughout; ≥ 3 real persisted prefs; SwiftData persistence with resume; light + dark first-class via `Theme.dyn`; Dynamic Type system fonts; accessibility labels/values on controls; Reduce-Motion-aware animation; sparse haptics gated by a setting; Pro gating with a paywall; sample data seeds a 50+ event history so Stats/Archive are lively.
- **Puzzles authored: 33** (30 Minis + 3 Midis).

*Honest note*: puzzle fills were produced by a constraint solver over a curated common-word list and then verified, rather than hand-set by a constructor; clues are concise but not professionally edited.
