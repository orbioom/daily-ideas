# Daub — Color-by-Number Pixel Art

Calming color-by-number puzzle app for iOS. 20 handcrafted pixel art designs. No ads, no timers, no pressure.

## Features

- **20 handcrafted puzzles** — 5 categories: Animals, Nature, Food, Objects, Patterns
- **Grid sizes**: 10×10 to 14×14 — easy to see, satisfying to fill
- **Color palette picker** — tap a color swatch, then tap cells to fill
- **Numbered cells** — each empty cell shows its color number for easy reference
- **Erase support** — tap a filled cell again to unpaint it
- **Auto-save** — progress persists in SwiftData between sessions
- **Completion alert** — celebration when a puzzle is finished
- **Progress bar** — real-time completion percentage per puzzle
- **Gallery view** — all puzzles with mini preview canvas showing current paint progress
- **Category filter** — filter gallery by Animals, Nature, Food, Objects, Patterns
- **Stats screen** — completed count, time painting, by-category bar chart, recent completions
- **Settings** — toggle cell numbers, highlight selected color, haptic feedback, reset all progress
- **Accessibility** — VoiceOver labels for every cell, Dynamic Type, Reduce Motion respected
- **Light & dark mode** — designed for both

## Screens

1. **Gallery** — all 20 puzzles in a 2-column grid with progress bars and mini previews
2. **Paint** — full painting canvas with scrollable grid, color palette bar, progress bar
3. **Progress** — stats with completion counts, time, by-category chart, recent completions
4. **Settings** — display options, haptics, reset

## Run Steps

1. `cd ios && xcodegen generate`
2. Open `Daub.xcodeproj` in Xcode 15+
3. Select a simulator or device
4. Product → Run

> Free signing: In Xcode → Signing & Capabilities, set your personal team.
