# Bingo

The ultimate bingo app — play classic number bingo (75-ball B-I-N-G-O), word bingo for parties and classrooms, auto-caller with voice, and track up to 6 cards simultaneously.

## Setup
1. Install XcodeGen: `brew install xcodegen`
2. cd ios && xcodegen generate
3. Open Bingo.xcodeproj in Xcode
4. Build and run on iOS 17+ device or simulator

## Features
- Classic 75-ball number bingo with B-I-N-G-O columns
- Word bingo with 5 themed packs + custom lists
- Auto-caller with AVSpeechSynthesizer
- Up to 4 cards simultaneously (6 with Pro)
- Win detection: rows, columns, diagonals, four corners, blackout
- Confetti celebration on win
- SwiftData persistence
- Full accessibility support
